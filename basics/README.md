## Start Here → `basics/`

| File | What you learn |
|------|----------------|
| `config.md` | Set your name & email |
| `init.md` | Create a new repo |
| `clone.md` | Copy a repo from GitHub |
| `add-commit.md` | Save your changes |
| `status-log.md` | Check what's going on |
| `push-pull.md` | Sync with GitHub |

---

## Learning Order (Beginner Path)

```
1. config       → set up Git on your machine
2. init         → create your first repo
3. add-commit   → save your work
4. status-log   → understand what changed
5. push-pull    → connect to GitHub
6. clone        → work with existing projects
```
